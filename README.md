# Muthumariappan Portfolio

Static HTML, CSS and JavaScript portfolio, ready to deploy to GitHub Pages.

## Customize before deployment

- Add your resume file and replace the `#` in the **Resume** button in `index.html`.
- Replace the placeholder GitHub and live-demo links in the Medical Chatbot card.
- Connect the contact form to Formspree, Netlify Forms, or your own backend.
- `assets/muthumariappan-portrait.png` is the supplied portrait. A background-replaced version can be swapped in with the same filename.
